# NGOConnect++ AI

## AI-Driven Smart City Social Welfare and NGO Collaboration Platform

NGOConnect++ AI is a Smart City social welfare intelligence
platform designed to connect citizens, NGOs, volunteers,
donors, beneficiaries, administrators, and community resources.

## Project Status

🚧 Under Development

## Architecture

The system follows a microservices architecture using:

- Spring Boot
- Spring Cloud
- Eureka
- API Gateway
- Spring Security
- JWT
- MySQL
- React
- Python
- Scikit-learn
- Spring AI

## Core AI Capabilities

1. Emergency Priority Prediction
2. AI Volunteer Matching
3. AI Resource Recommendation
4. Campaign Recommendation
5. NGO Risk / Anomaly Detection
6. Generative AI Assistant
